# Real-Time Communication Project

A real-time communication/chat application built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO

## Features

- Real-time messaging
- Username system
- Online user count
- Join notification
- Leave notification
- Typing indicator
- Message timestamps
- Responsive design
- Multiple users can communicate simultaneously
